# Contributing

Thanks for considering a contribution.

1. Open an issue to discuss significant changes.
2. Create a focused branch from `main`.
3. Keep changes small and include tests.
4. Run formatting, Clippy, and tests locally.
5. Open a pull request using the repository template.
6. Explain design trade-offs and any operational impact.

Do not commit credentials, `.env` files, generated build output, or private data.
All contributions are subject to the MIT license.
